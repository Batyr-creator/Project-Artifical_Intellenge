# Project-Artifical_Intellenge

Небольшой рекомендательный сервис фильмов и сериалов на Python, Flask и scikit-learn.

## Возможности

- Контентные рекомендации по жанрам, описанию, актёрам и режиссёру: TF-IDF и косинусное сходство.
- Рекомендации по оценкам зрителей: выберите фильм — сервис покажет другие фильмы, высоко оценённые зрителями, которым он понравился.
- Логические рекомендации на основе фактов о рейтингах и жанрах с прямым выводом новых фактов.
- Матрица контентного сходства сохраняется в `data/cache/content_similarity.pkl` и пересчитывается, когда меняется каталог.
- Русскоязычный веб-интерфейс и JSON API. В демонстрационных CSV есть 50 фильмов и 6 профилей.

## Логическая модель знаний

База знаний формируется из `movies.csv` и `ratings.csv`. Факты имеют вид `genre(фильм, жанр)`, `rating(зритель, фильм, оценка)` и `rated(зритель, фильм)`. Оценённый фильм с рейтингом от 4 считается понравившимся (`likes`). Исполняемая база продукционных правил определена в `knowledge_base.py`; каждое правило содержит условие, заключение и функцию, добавляющую новые факты в рабочую память.

База правил:

- `R1`: `rating(U, M, R) AND R >= 4 -> likes(U, M)` — высокая оценка означает, что фильм понравился.
- `R2`: `likes(U, M) AND genre(M, G) -> prefers_genre(U, G)` — жанры понравившегося фильма становятся предпочтениями зрителя.
- `R3`: `prefers_genre(U, G) AND genre(C, G) AND NOT rated(U, C) -> recommends(U, C)` — достаточно совпадения хотя бы по одному жанру (`OR`); исключаются только фильмы, уже оценённые выбранным зрителем (`NOT`), поэтому подходят и фильмы без оценок в каталоге.

Прямой вывод начинается с исходных фактов в рабочей памяти: на каждом цикле все правила сопоставляются с фактами, а новые заключения добавляются в память. Цикл завершается, когда новых фактов больше нет; исходные факты при этом не изменяются. Режим «По логическим правилам» использует этот вывод; фильмы с большим числом совпавших жанров идут первыми. Для каждого результата интерфейс показывает объяснение: какие понравившиеся фильмы вывели подходящие жанры и почему рекомендация прошла правила.

## Классификация оценок

`train_rating_classifier.py` строит `data/rating_classification.csv` из оценок, жанров, описаний фильмов и вкусов зрителей. Цель `liked`: оценка не ниже 4. Сравниваются TF-IDF с логистической регрессией, простая нейросеть MLP с двумя скрытыми слоями (32 и 16 нейронов) и прогноз большинства. Проверка GroupKFold полностью исключает зрителя из обучения соответствующего фолда. После проверки обе обученные модели сохраняются в `data/cache/`, отчёт с метриками и примерами распознавания — в `data/rating_classification_metrics.json`. Запуск: `python train_rating_classifier.py`.

На главной странице в разделе «Результаты обучения» отображаются метрики трёх вариантов, сгруппированные ошибки нейросети, примеры её распознавания и выборка с именами зрителей, названиями фильмов и раздельными признаками. JSON-ответ также доступен через `GET /api/classification/results`.

В демонстрационных данных всего 54 оценки от 6 зрителей, поэтому метрики нестабильны. GroupKFold проверяет перенос на незнакомого зрителя; результаты нужно считать предварительными и пересчитать на более крупном наборе данных.

## Фреймовая модель

Фреймы описывают объекты каталога и зрителей. Иерархия предметной области: `Сущность → Медиапроизведение → Фильм` и `Сущность → Участник → Зритель`. Дочерние фреймы наследуют свойства и связи родителей: у `Фильма` есть идентификатор сущности, название, год, описание, а также связи с жанрами, режиссёром и актёрами; у `Зрителя` есть унаследованные идентификатор и имя участника, а также связь с оценёнными фильмами.

Экземпляры фреймов строятся из каталога фильмов, профилей и оценок. `GET /api/frames` возвращает дерево иерархии с описанием свойств и связей и все экземпляры. В разделе базы знаний можно искать фильмы и зрителей по свойствам и изменять свойства выбранного объекта. Изменения хранятся в памяти до перезапуска приложения и не меняют исходные CSV.

Семантическая сеть представляет фильмы, зрителей, жанры, режиссёров и актёров отдельными узлами; рёбра показывают отношения `has_genre`, `directed_by`, `features` и `rated`. В разделе экземпляров можно искать связанные с объектом узлы и переходить по связям к другим фильмам или зрителям.

## ИИ-помощник

Помощник использует локальную модель Ollama: запросы не отправляются в OpenAI, API-ключ и платная подписка не нужны. Модель запускается на той же машине, где работает приложение, и использует её память и вычислительные ресурсы.

```bash
ollama pull qwen2.5:3b
```

Установите Ollama с [ollama.com](https://ollama.com/), затем скачайте модель указанной командой. Ollama должен работать на той же машине, что и Flask: на macOS и Windows запустите установленное приложение Ollama, на Linux при необходимости выполните `ollama serve` в отдельном терминале. В другом терминале запустите сервис проекта:

```bash
python app.py
```

По умолчанию используется `qwen2.5:3b`: более крупная `qwen2.5:7b` в Codespace с ограниченной памятью не запускается надёжно. Выбрать другую установленную модель можно переменной `OLLAMA_MODEL`, а адрес Ollama — `OLLAMA_BASE_URL`. Проверить соединение и наличие модели можно через `GET /api/assistant/status`. Запросы отправляются через `POST /api/assistant` в JSON-формате `{"question":"..."}`; текст запроса ограничен 2000 символами.

## API

- `GET /api/catalog` — каталог фильмов.
- `GET /api/popular` — шесть фильмов с наибольшим числом оценок; ответ включает среднюю оценку и количество оценок.
- `GET /api/profiles` — демонстрационные профили зрителей.
- `GET /api/comments?movie_id=1` — пользовательские отзывы к фильму.
- `POST /api/comments` — сохранить отзыв с автором, текстом и оценкой от 1 до 5.
- `GET /api/frames` — иерархия фреймов, их свойства, связи и экземпляры.
- `GET /api/frames/network` — узлы и типизированные рёбра семантической сети.
- `GET /api/frames/1/related?q=Science%20Fiction` — связанные узлы объекта с фильтрацией по тексту; параметр `relation` ограничивает тип связи.
- `GET /api/frames/search?q=Интерстеллар&class=Фильм` — поиск экземпляров по свойствам, с необязательным фильтром класса.
- `PATCH /api/frames/1/properties` — обновить свойства экземпляра, например `{"properties":{"title_ru":"Новое название"}}`; ID и связи менять нельзя.
- `GET /api/recommendations?mode=content&movie_id=1` — похожие фильмы.
- `GET /api/recommendations?mode=collaborative&movie_id=1` — другие фильмы с высокими оценками от зрителей, которым понравился выбранный фильм.
- `GET /api/recommendations?mode=logic&user_id=viewer_01` — рекомендации, полученные логическим выводом; у каждой есть поля `matched_genres` и `explanation`.

Запуск тестов: `python -m unittest discover -s tests -v`.
